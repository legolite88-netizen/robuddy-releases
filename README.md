# RoBuddy for Windows

Your local Roblox development companion, with Codex integration and official Claude Code terminal support.

## Download and install

[**Download RoBuddy for Windows**](https://github.com/legolite88-netizen/robuddy-releases/releases/latest/download/RoBuddy-Windows.zip) · [Latest release](https://github.com/legolite88-netizen/robuddy-releases/releases/latest)

1. Download and extract **RoBuddy-Windows.zip**.
2. Double-click the **RoBuddy Setup** installer inside.
3. Open **START HERE.html** for the setup guide. Link your open Roblox Studio game and connect your own supported AI account.

Windows 10/11, 64-bit. The installer creates shortcuts, opens the app, and installs its Studio plugin automatically. A RoBuddy account is not required.

## Automatic updates

RoBuddy 0.3.0 and later checks this public channel while open. New releases update the app and its matching plugin when your current work has finished, preserving projects and conversations. Verified old RoBuddy plugin copies are removed; unrelated Studio plugins stay in place. Save and reopen Studio normally to load an updated plugin.

If you installed 0.2.2 or earlier, install the current version once to join this channel.
